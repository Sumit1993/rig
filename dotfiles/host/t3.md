# Host: T3 Code
Applies only when your tools include `delegate_task`. Where it names a tool, it wins over the harness overlay.

- Wait on a background job: `t3_background_wait`. Never poll a delegate; follow its `next`.
- Watch a PR: `watch_pull_request`, then end the turn; `unwatch_pull_request` before handing back.
- PR watcher: a session that pushes PRs launches one top-level Sonnet 5.5 thread with `t3_thread_launch`. It holds every `watch_pull_request`, follows `scripts/coderabbit-routine/PROMPT.md` when a watched PR's checks settle, and wakes the organizer with `t3_thread_send` only for red CI, new findings or a mergeable PR.
- Idle compaction: T3 compacts only after the prompt cache has expired. The organizer and the watcher end each turn by moving their own bound one-shot `schedule_task` with prompt `/compact` to 50 minutes out.
- Ask the operator: in the reply. A secret only they hold: `request_secret`.

# Host: T3 Code
Applies only when your tools include `delegate_task`. Where it names a tool, it wins over the harness overlay.

- Follow-up for a subagent you spawned inside the prompt-cache hour: send it a message with the harness's own tool, never a new spawn. A new review or re-check still spawns fresh.
- Spawn a subagent: the harness's own tool for a model of your provider; `delegate_task` for another provider's model (Sol from Claude, Opus from Codex) or a separate worktree. Call `orchestrator_capabilities` once before the first `delegate_task`.
- Seats: reach each through the line above, never a CLI route; a model the host cannot reach is reported.
- Wait on a background job: `t3_background_wait`. Never poll a delegate; follow its `next`.
- Watch a PR: `watch_pull_request`, then end the turn; `unwatch_pull_request` before handing back.
- Ask the operator: in the reply. A secret only they hold: `request_secret`.
